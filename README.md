# Heart Disease Prediction Using Machine Learning

# Project Overview

Heart Disease Prediction is a Machine Learning-based project that predicts the possibility of heart disease using patient health-related input data.

The project uses Python and Machine Learning techniques to analyze health parameters and generate prediction results through a web-based dashboard.

# Project Objectives

- Analyze health-related data to identify patterns.
- Apply Machine Learning techniques for heart disease prediction.
- Build a user-friendly web application using Flask.
- Display prediction results through an interactive dashboard.

# Installation and Setup

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/heart-disease-prediction-ml.git
```

## 2. Navigate to the Project Folder

```bash
cd heart-disease-prediction-ml
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Run the Application

```bash
python app.py
```

## 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://127.0.0.1:5000/
```
